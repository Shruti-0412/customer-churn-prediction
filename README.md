# Customer Churn Prediction using Machine Learning

## 📌 Overview

Customer Churn Prediction is a Machine Learning project developed to identify customers who are likely to discontinue a company's services. The project helps organizations improve customer retention strategies by analyzing customer behavior and predicting churn probability using historical customer data.

This project applies machine learning techniques to classify customers into churn and non-churn categories based on features such as tenure, monthly charges, contract type, internet services, and payment methods.

# 📊 Exploratory Data Analysis (EDA)

EDA was performed to understand customer behavior patterns and identify factors affecting churn.

## Key Insights

- Customers with month-to-month contracts churn more frequently.
- Higher monthly charges increase churn probability.
- Long-term customers are less likely to churn.
- Contract type significantly affects customer retention.
